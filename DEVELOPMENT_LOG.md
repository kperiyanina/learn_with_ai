# Журнал разработки LearnWithAI

## Этап 0. Подготовка и стабилизация проекта

**Статус:** выполнен  
**Дата:** 2026-09-29

### Что сделано

- Добавлен `config.py` для централизованной загрузки конфигурации из `.env`.
- Добавлены настройки:
  - `GROQ_API_KEY`;
  - `GROQ_MODEL`;
  - `DATABASE_PATH`.
- Добавлены файлы:
  - `requirements.txt`;
  - `.env.example`.
- Путь к SQLite-базе теперь определяется относительно проекта и может быть переопределён через `DATABASE_PATH`.
- В SQLite включена проверка внешних ключей.
- Инициализация клиента Groq перенесена внутрь функции генерации плана. Приложение может запуститься без API-ключа, а ошибка показывается только при обращении к AI.
- Убрана жёсткая привязка к модели Groq: модель задаётся через `GROQ_MODEL`.
- Обработка Markdown-обёртки вокруг JSON-ответа AI вынесена в отдельную функцию.
- Сообщение об ошибочном JSON от AI сделано безопаснее: полный ответ модели не выводится пользователю.
- Добавлено логирование ошибки генерации учебного плана.
- Тестовые файлы переработаны:
  - убраны внешние вызовы AI при импорте;
  - добавлены изолированные unit-тесты;
  - тесты проверяют обработку JSON и локальный генератор плана.
- `.gitignore` дополнен правилами для `.pytest_cache` и `.streamlit`.
